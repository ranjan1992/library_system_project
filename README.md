# Library System Project

It is a Library System Project in which we can search books and have the data of all books that are present inside a library. The project has functionalities which includes:

- Search functionality to browse books on the go.
- Filter books based on authors, names.
- Form through which we can add books and add them to the library.
- Delete books that we donot want to include inside the library

## How to Run ?

Please follow steps to run the project smoothly:

- Clone the project through Github Repo.
- Run **npm install** on terminal
- Run **npm run dev**
- Project is started !

## What we have used ?

We have used Modern React along with Vite and CSS3 to make Application dynamic. We have also used Redux Toolkit for State Management so as to avoid props drilling and imporving code efficiency. The project is responsive in nature and it is great for all screens.
